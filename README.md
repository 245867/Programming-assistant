# 编程助手

一款面向 Windows 的开发辅助工具。把平时零散要开好几个小程序的事情收在一起：发个请求、看窗口结构、查进程、验编码、写正则、准备 YOLO 数据集。它不打算替代 IDE，只希望在需要这些工具时，少找一次、少切一次。

它更像一个随手放在桌面上的工作台，而不是一套庞大的开发环境。打开一个程序，按需要进入对应页面，用完就关；不要求先建工程，也不把简单的检查任务变成一条复杂流程。

底层是原生 C++，界面使用 WebView2。Windows 能力直接调，工具页面按模块加载。日常使用只需要这个桌面程序，YOLO、Python 等专项功能才需要额外准备本机依赖。

## 功能一览

### 网络与接口

- HTTP 请求：方法、URL、查询参数、请求头、请求体、响应头和响应内容集中查看
- 支持从 cURL 直接导入请求，便于复现接口问题
- 显示 HTTP 版本与基础请求信息，代理地址可单独配置和验证
- WebSocket 连接、收发消息和连接状态检查

### 文本与数据

- UTF-8、GBK 等常见编码转换，配合 Base64、URL 编码和十六进制查看
- MD5、SHA 等哈希计算，适合核对文件、参数或接口签名
- JSON 格式化、压缩和结构查看，不必为看一段响应单独开工具
- 路径解析、常见语言代码片段，以及十进制 / 十六进制 / 二进制计算器

### Windows 检查

- 窗口 Spy：查看窗口层级、句柄、类名、标题、样式和矩形信息
- MSAA 信息查看，辅助定位传统桌面程序的控件结构
- 屏幕取色、进程查看与管理、文件和目录定位
- 代理连通性检查、正则表达式测试和 JavaScript 小脚本测试

### YOLO 与图像

- 检查 Python、Ultralytics 和模型环境，减少环境问题对推理的干扰
- 准备训练命令、浏览数据集、绘制和调整训练标签
- 使用 ONNX 或 `.pt` 模型进行检测，查看置信度、矩形和类别结果
- 记录推理耗时，支持从结果直接定位图片所在目录

这些页面彼此独立。只想验一个接口时，不需要打开 YOLO 环境；只想看一个窗口时，也不需要准备项目文件。

## 为什么保持轻便

- 本体是 Windows 桌面程序，不需要为每个小任务分别安装一套工具
- 页面按功能拆开，打开后直接操作，不依赖账号、云端服务或项目模板
- 测试版直接读取仓库里的 `web/` 页面，改动界面时可以快速编译验证
- 专项依赖按需安装：普通工具不依赖 Python；YOLO / CNN 只在使用时准备对应运行时和模型

## 构建

项目面向 Windows x64，使用 Visual Studio 2019 或兼容的 C++ 工具链。

1. 打开 `project/ProgrammerAssistant.sln`。
2. 选择 `Release | x64` 编译，或在 PowerShell 执行 `./编译测试版.ps1`。
3. 从仓库根目录启动生成的 `编程助手.exe`。

测试版会直接读取 `web/` 目录。正式发布版依赖 `app.japk`，需先按项目的 JadePack 流程完成打包。

## YOLO 与 CNN

YOLO 页面支持 `.pt` 和 ONNX 检测模型；Python、Ultralytics 与模型依赖需要在本机准备好。

CNN 测试与 YOLO 流程相互独立。带自定义 Caffe 层的模型需要对应运行时，或先转换为 ONNX；OpenCV DNN 并不能执行所有 Caffe 自定义层。
